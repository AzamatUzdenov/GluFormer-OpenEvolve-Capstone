ТРЕБОВАНИЯ CAPSTONE И СТАТУС
Проверено 2 ноября 2026:
https://khanlab.bio/cbio7501-f26/assessment/capstone-rubric.html

Семь направлений рубрики, внутренние веса пока предварительные.
Ниже статус, а не оценка или прогноз балла.

1. Чистый клон: рабочий запуск, успешная проверка GitHub на версии релиза,
   реальный отчёт партнёра. Пока отсутствует, reproduce возвращает код 2.
2. Структура и данные: проверяемая загрузка, источники и контрольные суммы,
   исходные файлы без изменений и вне Git. Структура готова, данные не выбраны.
3. Окружение: согласованные pixi.toml/pixi.lock, программы из окружения,
   проверенные платформы. Пока только предварительный pixi.toml из шаблона.
4. Автоматизация: одна команда строит весь результат, настройки отдельно.
   Создан config/project.json с незаполненными полями, анализа нет.
5. Отчёт Quarto: вычисляемые результаты, подписи, альтернативный текст,
   версии программ. Пока только папка, отчёта нет.
6. История: небольшие коммиты, pull requests и релиз. Пока локальная подготовка,
   GitHub capstone и релиз не создавались.
7. Документация: README, доступность данных, лицензии, CITATION.
   README описывает незавершённость; CITATION предварительный; лицензии
   выбранных кода, текста и данных пока неизвестны.

Сдача: GitHub-репозиторий, релиз сдаваемой версии, отчёт партнёра.
Репозиторий может быть private. DOI Zenodo для capstone не обязателен.
Размер и научная новизна анализа сами по себе не являются критериями.

Ближайший результат: кратко описать свой проект и его данные. В объявлении
26 октября преподаватель просит внести название и описание в таблицу курса.
Пока их нельзя подготовить по существу: исходная работа не выбрана.
https://lms.mbzuai.ac.ae/mod/forum/discuss.php?d=5674
https://khanlab.bio/cbio7501-f26/schedule-course.html

LTEE оценивается отдельно; его вопрос и результат не заменяют capstone.
https://khanlab.bio/cbio7501-f26/assessment/ltee-project.html

Checker главным образом проверяет наличие файлов и ключевых слов. Его yes
не подтверждает рабочий анализ, качество README или научный вывод. Пункт DOI
в самом checker помечен как необязательный для capstone.
