# Code of conduct

This project follows the [Contributor Covenant 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)
in issues, pull requests, and project discussions. Treat contributors with
respect, give constructive feedback, and respect privacy.

Report unacceptable behavior privately to the maintainer,
[Azamat Uzdenov](mailto:azamuzdenov@gmail.com).
