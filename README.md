## Что воспроизводим

Следующий шаг: выбрать один вопрос, набор входных данных и один результат из
указанной пользователем работы. Затем проверить материалы и заполнить
`config/project.json`. [Рубрика преподавателя](https://khanlab.bio/cbio7501-f26/assessment/capstone-rubric.html).

## Данные (data)

Источник, версия, лицензия, доступность и размер пока неизвестны.
`metadata/data_sources.tsv` содержит только заголовок, а не найденные источники.
После выбора работы добавить проверенную загрузку, контрольные суммы и описание
полей. Исходные данные хранить без изменений в `data/raw/`, вне Git.

## Повторение результата (reproduce)

Полного запуска пока нет. `scripts/reproduce.py` намеренно завершается с кодом 2
и объясняет, что исходный анализ ещё не подключён. Успешный пустой запуск не
будет выдаваться за воспроизведение результата.

После подключения анализа целевые команды:

```bash
pixi install --locked
pixi run reproduce
```

`pixi.toml` пока содержит предварительные зависимости из шаблона. `pixi.lock`
будет создан после проверки требований выбранного кода. Окружение анализа ещё
не установлено. Шаблон GitHub Actions находится в `.github/workflows/reproduce.yml`,
но удалённый репозиторий capstone не создан.

## Результаты (output)

Конкретная таблица, рисунок или метрика ещё не выбраны. После выбора указать пути
выходных файлов и правило сравнения с исходной работой. Результаты создаёт код
в `results/`; отчёт Quarto в `reports/` получает числа и рисунки из расчёта.
На этом этапе научных результатов нет.

текущей рубрике необязателен.
